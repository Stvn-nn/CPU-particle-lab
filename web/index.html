What is being measured

Motion and recovery

Ring, sphere, and helix use repeatable shape paths. Cube particles follow free reflected paths inside a box. Pushing adds a local displacement; motion-enabled recovery returns it to the original moving path.

Model scope

The bundled neural network learned synthetic displacement transitions at 60 simulation steps per second. Predictions outside its training range are skipped. This is a shape-motion lab, not a fluid solver or particle collision model.

Performance scope

WebGL updates particle state in graphics buffers. Browser settings may use hardware or a software renderer. This app does not claim hardware identity or system-wide memory use. Use the CPU mode for a reference implementation.

Reproducibility

Save a setup to reproduce its starting formation and controls. CSV exports contain real timing samples and settings. Resizing changes drawing cost. Background tabs pause automatically; long stalls do not cause large simulation jumps.
